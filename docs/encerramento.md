# Agora é com você

[![QR code para o repositório do minicurso](assets/repositorio-qr.svg)](https://github.com/vmenezesdev/minicurso-codemagic-android)

**[github.com/vmenezesdev/minicurso-codemagic-android](https://github.com/vmenezesdev/minicurso-codemagic-android)**

1. Abra o repositório e dê uma **Star** para marcar o material.
2. Clique em **Fork → Create fork** para criar sua cópia.
3. Siga **[Comece por aqui](../README.md#comece-por-aqui)** para conectar o fork ao Codemagic.
4. Faça a **[tarefa de casa](tarefa-de-casa.md)**: personalize o app, observe uma falha, corrija e gere o APK.
5. Registre os resultados em `ENTREGA.md` no seu fork.
